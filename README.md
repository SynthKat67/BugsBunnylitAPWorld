# BugsBunnylitAP
AP world distribution for Bugs Bunny Lost in Time


how to use:

1. install the bugsbunnylit.apworld
2. download or generate the yaml
3. if you're using Bizhawk 2.7 or 2.8, got to Config > Customize. On the Advanced tab, switch the Lua Core from NLua+KopiLua to Lua+LuaInterface, then restart EmuHawk. (if you're using Bizhawk 2.9 or higher, you can skip this step.)
4. run Bizhawk Client on AP Launcher
5. run Bizhawk, open the game and open bizhawk_generic.lua
6. the handler will be recognized in the main menu
7. enjoy


TROUBLESHOOTING

left a level and merlin hasn't appeared?

just wait and he should, not doing so can cause issue so make sure you talk to merlin after leaving a level

checks not sending through?

save the game, and close/reopen the client, that's a desync issue, it will fix upon reconnecting
